# UtilityX-Core

**UtilityX-Core** is a **non-bloated, modular alternative to EssentialsX**. Instead of one massive plugin with hundreds of unused commands, UtilityX is built around a **lightweight core** that powers only the features you choose to install.

With an intuitive **in-game GUI** and a flexible **add-on system**, UtilityX gives server owners full control — without the clutter.

> 🧩 Minimal by default. Powerful when extended. Essentials reimagined.

---

## ⚙️ Core Philosophy

- 🚫 **No Bloat** – Only run what you enable. Nothing more.
- 🧱 **Modular Architecture** – Each command set or feature is its own add-on.
- 🧠 **Smart Core** – Handles routing, data, and plugin lifecycle.
- 🎮 **Chest GUI** – Manage all modules from inside the game.
- ⚡ **Fast & Lightweight** – Designed with performance in mind.

---

## 🧩 Features

- ✅ EssentialsX Replacement (by modular design)
- 📦 Dynamic add-on loading from a single folder
- 🗂 Toggle modules via in-game chest GUI (`/utilityx`)
- 💾 Saved module states in YAML
- 🛠 Central configuration + data handling
- 🔌 Vault permissions support
- 🧑‍💻 Developer-friendly API

---

## 🚀 Getting Started

1. **Download** `UtilityX-Core.jar`
2. **Place** it into your server’s `/plugins/` folder
3. **Start your server** – a `/UtilityX/` folder with `addons/` will be generated
4. **Drop add-ons** (like `UtilityX-Homes.jar`) into `/plugins/UtilityX/addons/`
5. **Use `/utilityx` in-game** to open the module GUI and enable what you need
